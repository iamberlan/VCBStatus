# Roblox Voice Ban Status

A Chromium extension popup showing only voice ban status and time remaining when banned.

## Install

1. Sign in to Roblox regularly.
2. Download this repository and extract it somewhere on your computer.
3. Open `chrome://extensions` (or `edge://extensions`).
4. Enable **Developer mode**, click **Load unpacked**, and select the folder you extracted.
5. Open the extension from the browser toolbar.

The popup checks `https://voice.roblox.com/v1/settings` using your existing browser session. When your voice chat ban expires, a notification will be pushed (disablable in the extension menu).
